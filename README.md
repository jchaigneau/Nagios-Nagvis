# Nagios Core + NagVis + MK Livestatus sur Debian 13

Installation automatisée de Nagios Core, MK Livestatus et NagVis sur Debian 13 (Trixie).

Ce projet fournit des scripts permettant de déployer une plateforme de supervision basée sur :

- Nagios Core 4.5.14
- MK Livestatus 1.5.0p24
- NagVis
- Apache 2
- PHP
- Nagios Plugins
- SNMP
- Debian 13

L'objectif est d'obtenir une installation reproductible de Nagios avec visualisation graphique via NagVis et communication avec Nagios par MK Livestatus.

-----------

Login nagios : nagiosadmin / ChangeMe123!
Login nagvis : admin / admin

-----------

Les composants installés par ce projet conservent leurs licences respectives.
Consultez les projets officiels Nagios Core, NagVis et Checkmk/MK Livestatus pour leurs conditions de licence.

-----------

Ce projet est fourni comme outil d'automatisation et d'aide au déploiement.

Il est recommandé de tester les scripts dans une VM ou un environnement de laboratoire avant toute utilisation en production.
